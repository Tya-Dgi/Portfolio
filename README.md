# Portfolio

Nitya Kudugi's personal portfolio. Nitya studies Biomedical Engineering
Technology at NJIT and hopes to become a prosthetics engineer or a prosthetist.

## View locally

Double-click `index.html` to open it in your browser, or use VS Code Live Preview.
No installation, build step, or server is required.

## Progress

The Home page uses a pastel-purple spring palette and a responsive navigation
menu. Projects includes a playable Rock Paper Scissors game with random computer
moves, win/loss/tie scores, a reset button, and accessible result announcements.
The browser game was developed with Codex assistance, based on the student's
class project. It uses plain JavaScript and works locally without a server.
The Projects page also has expandable writing-project cards with original SVG
concept illustrations. Click a card or focus it and press Enter to reveal its
overview; these native HTML controls also work without JavaScript. Illustrations
are symbolic graphics, not screenshots of the student's papers. Original project
documents still need to be supplied. About, Skills, and Contact remain future
tasks, and their navigation labels are currently inactive. Full browser and
live-site accessibility testing are still outstanding.
