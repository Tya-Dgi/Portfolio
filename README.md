# Portfolio

Nitya Kudugi's personal portfolio. Nitya studies Biomedical Engineering
Technology at NJIT and hopes to become a prosthetics engineer or a prosthetist.

## View locally

Double-click `index.html` to open it in your browser, or use VS Code Live Preview.
No installation, build step, or server is required.

## Progress

The Home page uses a pastel-purple spring palette and a responsive navigation
menu. About, Projects, Skills, and Contact will be added in subsequent tasks;
their navigation labels are currently inactive. A second JavaScript interaction,
and full live-site testing are still outstanding.

## Git workflow

AGENTS.md instructs Codex to test, commit, and push completed changes without
requesting approval again. This is an agent instruction, not a background watcher
for manual editor saves.
