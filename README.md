# Portfolio

Nitya Kudugi's personal portfolio. Nitya studies Biomedical Engineering
Technology at NJIT and hopes to become a prosthetics engineer or a prosthetist.

## View locally

Double-click `index.html` to open it in your browser, or use VS Code Live Preview.
No installation, build step, or server is required.

## Automatic pushes

The student authorized automatic pushes on October 29, 2026. In VS Code, allow
automatic tasks for this folder when prompted, or select **Terminal > Run Task >
Portfolio: auto-push saved changes**. Keep that task running while editing.
The watcher commits and pushes after ten seconds without saved website changes;
GitHub Pages then rebuilds the site. Unsaved editor changes are not published.

The watcher includes HTML, CSS, JavaScript, images in `images/`, and the named
project documents listed in its script. Other files require a deliberate commit.
It stops on errors, including rejected pushes; resolve the error and restart the
task. It never force-pushes. Stop it with Ctrl+C in its terminal or Terminate Task.
It does not run when the computer is off or after its process closes, and it does
not run browser accessibility tests before each automatic commit.
